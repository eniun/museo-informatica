    Tarjeta gráfica NVIDIA PCI Express

    Tres salidas de vídeo y refrigeración con ventilador

    Toca un número para descubrir esa parte.

    1
    Ventilador y disipador

    Enfrían el chip gráfico, que está debajo.

    Esta tarjeta gráfica NVIDIA se conecta a una ranura PCI Express. Lleva memoria de vídeo y un disipador con ventilador para evacuar el calor del chip gráfico.

    Tiene tres salidas: VGA para monitores antiguos, DVI para pantallas digitales y una salida de televisión.

    Función

    Una gráfica de esta época ya no solo dibuja ventanas: calcula escenas en 3D, reproduce vídeo y dibuja los efectos del escritorio de Windows Vista.

    El chip gráfico calcula las imágenes y utiliza la memoria de vídeo para guardar datos como texturas e imágenes. El ventilador y el disipador ayudan a evacuar el calor que produce.

    La conexión PCI Express utiliza carriles de datos independientes. El número de carriles depende del modelo de tarjeta y de su conexión.

    Comparativa

    Compara esta tecnología con otros equipos y soluciones.

    Dos formas de enfriar una gráfica

    Esta tarjeta NVIDIAAletas metálicas con ventilador
    Diamond AGP del museo (011)Aletas metálicas sin ventilador

    Las dos usan un disipador, un bloque de metal con aletas que libera calor. La NVIDIA añade un ventilador para mover aire. La otra tarjeta también pertenece al museo; no es un ejemplo moderno.

    Qué pantallas puedes conectar

    Esta tarjeta NVIDIAMonitor por VGA o DVI; televisor por salida de TV
    MSI RTX 4060 Gaming X NV 8GPantalla por HDMI o DisplayPort

    Cada pantalla necesita una conexión compatible. Los nombres indican tipos de conector; que dos tarjetas sirvan para dar imagen no significa que acepten el mismo cable.

    ¿Sabías que…?

    • Las conexiones de vídeo cuentan parte de la historia de una tarjeta: esta reúne VGA y DVI, además de una salida de televisión.

    • Las salidas de televisión permitían usar un televisor como pantalla, algo habitual para ver películas desde el ordenador.
