    Pieza 0061991Placa base

    Placa base 386 con AMD Am386DX

    Treinta y dos bits para el PC

    Toca un número para descubrir esa parte.

    1
    Procesador AMD Am386DX

    El cerebro del ordenador: un 386 de 32 bits a 25 MHz fabricado por AMD.

    Esto es una placa base: la placa principal del ordenador, donde se conectan el procesador, la memoria y las tarjetas. Lleva un procesador AMD Am386DX de 32 bits a 25 MHz.

    La placa tiene siete ranuras ISA para tarjetas, ocho para módulos de memoria y un zócalo vacío para un coprocesador matemático.

    2

    Función

    La placa base une todas las piezas del ordenador. El procesador ejecuta los programas, la memoria guarda lo que se está usando y las ranuras permiten añadir tarjetas.

    El 386 fue el primer procesador de 32 bits de la familia del PC. Podía manejar mucha más memoria que sus antecesores y permitió usar entornos gráficos como Windows 3.

    Las operaciones con decimales eran lentas en el 386. Por eso las placas traían un zócalo para un coprocesador matemático, que se compraba aparte para programas de cálculo o diseño.

    Comparativa

    Compara esta tecnología con otros equipos y soluciones.

    El reloj que marca el ritmo

    ×100
    Esta pieza25 MHz
    Intel Core i5-12400 (2022)2,50 GHz de frecuencia base

    Como un metrónomo, el reloj marca el ritmo de los circuitos: 25 millones de pulsos por segundo frente a 2500 millones. Eso es unas 100 veces más pulsos, pero no significa que los programas sean 100 veces más rápidos: cada procesador trabaja de forma distinta.

    Hacer cálculos con decimales

    Esta piezaUn chip adicional para ayudar con esos cálculos
    Procesador de PC modernoEsa ayuda ya está dentro del procesador

    Los cálculos con números como 3,14 podían acelerarse añadiendo un chip opcional llamado 387. El procesador moderno ya incluye los circuitos para hacer ese trabajo, sin instalar ese chip aparte.

    Cambiar o ampliar la memoria

    Esta piezaUna tira de memoria con 30 contactos
    Memoria DDR5 de sobremesaUna tira de memoria con 288 contactos

    Las tiras de memoria se enchufan a la placa por sus contactos metálicos. La antigua se llama SIMM y la del ejemplo moderno, DDR5. No tienen la misma forma ni encajan en el mismo sitio; el número de contactos no dice cuántos datos caben.

    ¿Sabías que…?

    • AMD fabricaba procesadores compatibles con los de Intel. Tras un largo pleito con Intel, lanzó el Am386 en 1991 y llegó a venderlo a más velocidad que el 386 de Intel.

    • La placa lleva una pegatina que dice «THAILAND», donde se fabricó.
